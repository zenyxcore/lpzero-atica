# Áticas — Landing Page Demo

Demonstração de landing page para marca fictícia de imobiliária de alto padrão.

> **Aviso:** Este projeto é uma demonstração educacional. A marca Áticas é fictícia.
> Nenhum imóvel está à venda e nenhum serviço real é oferecido.

## Estrutura

```
atica-lp-demo/
├── index.html       # Página única
├── public/
│   ├── logo.png     # Logotipo Áticas (PNG transparente)
│   ├── hero.jpg     # Pôster de fallback do hero
│   ├── hero-video.mp4 # Vídeo 1920×1080 de fundo do hero
│   ├── brand-story-aticas.webp # Visual editorial da seção sobre
│   └── port*.jpg/png # Imagens da curadoria
└── vercel.json      # Configuração de deploy
```

## Identidade Visual

- **Tipografia:** Playfair Display (títulos) + DM Sans (corpo)
- **Cores:** Grafite `#202321` · Marfim `#FAF9F5` · Verde Lima `#A9B84A` · Cinza `#6F716A`
- **Estilo:** Editorial, minimalista, alto padrão
