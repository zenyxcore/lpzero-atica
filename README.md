# Áticas — Landing Page Demo

Demonstração de landing page para marca fictícia de imobiliária de alto padrão.

> **Aviso:** Este projeto é uma demonstração educacional. A marca Áticas é fictícia.
> Nenhum imóvel está à venda e nenhum serviço real é oferecido.

## Estrutura

```
atica-lp-demo/
├── index.html       # Página única
├── public/
│   ├── logo.png     # Logotipo Áticas (PNG transparente)
│   └── hero.jpg     # Imagem principal do hero
└── vercel.json      # Configuração de deploy
```
